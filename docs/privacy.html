Privacy

The short version

Mimir has no servers, no accounts, and no analytics. There is nowhere for your data to be sent, because nothing was built to receive it. Everything below is verifiable in the source.

Two things reach the network, both optional and both obvious. Web search, which ships switched off and is toggled per session from the input bar. And the update check, which asks GitHub whether a newer release exists. That is the complete list.

On disk

What is stored, and where

All of it sits in one folder, outside the install directory so updates never touch it.

PlatformLocation
Windows%LOCALAPPDATA%\Mimir\data\
macOS~/Library/Application Support/Mimir/data/
Linux~/.local/share/Mimir/data/
FileContents
mimir.dbConversations, subjects, topics, quiz history, spaced-repetition state, your account
chroma/Embedded vectors for semantic recall — your documents and past turns
uploads/The PDFs and images you uploaded, as you uploaded them
user_settings.jsonModel choice, temperature, context window, study preferences

Deleting that folder resets Mimir to first launch. Copying it to another machine carries everything across. There is no export step because there is no proprietary format holding it hostage — SQLite and a Chroma directory, both readable by ordinary tools.

Accounts

The login is local

Mimir asks you to register, which looks like a cloud account and is not one. The record is a row in the SQLite file on your disk. Passwords are hashed with bcrypt, sessions are JWTs signed locally. It exists so several people can share a computer without sharing study history — no server ever sees a credential, because there is no server.

A forgotten password cannot be reset by email, for the same reason. Delete the database, or ask on the issue tracker.

The exceptions, in detail

When Mimir talks to the internet

Web search — off by default

With the WEB toggle lit, your question is sent to DuckDuckGo and the results are handed to the local model to answer from. DuckDuckGo therefore sees that query, subject to their privacy policy — nothing else goes with it: not your notes, not your history, not who you are.

Switched off, no search request is made at all. The tool is not merely unused, it is not registered with the agent, so there is no code path that could call it by accident.

Update check

Mimir asks the GitHub Releases API whether a version newer than yours exists. GitHub sees a request for a public file, as it would from any browser. No identifier is attached.

Fonts

The interface loads Cinzel and Crimson Text from Google Fonts on first run, then caches them. This website does the same. It is the one request neither strictly needs, and a self-hosted fallback is on the list.

Not present, at all: telemetry, crash reporting, usage analytics, A/B testing, advertising identifiers, third-party SDKs, cloud sync, and model-provider API calls. Your questions are never used to train anything.

Verify it

Do not take my word for it

The whole application is open source. If you want to confirm the claims on this page rather than trust them:

  • Read the source — the only outbound calls are in the web-search tool and the updater
  • Watch the traffic — run it behind a proxy or packet capture and see for yourself
  • Pull the plug — disconnect from the network entirely; everything but search keeps working
  • Open the database — mimir.db is plain SQLite; inspect exactly what is kept
